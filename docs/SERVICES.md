# External Services & Integrations

## 1. Supabase (Database & Storage)
- **Database**: We use Supabase PostgreSQL. 
  - **Connection Pooling**: Defined by `DATABASE_URL` in `.env`. Must use the connection pooler (port 6543) in production environments to support serverless concurrency.
  - **Direct URL**: Defined by `DIRECT_URL` in `.env`. Only used by Prisma during `npx prisma migrate` or `npx prisma db push` (port 5432) to alter schema.
- **Storage**: Supabase Buckets are used for attachments, PDFs, and portfolio media.
  - Files are uploaded directly from the client via Presigned URLs generated by the server. 
  - File constraints (MIME types, size limits) are verified on the server before issuing the token.

## 2. Resend (Email & Communications)
- **Outbound**: The `Resend` Node SDK is used inside Server Actions. When sending an Invoice or Quotation, the system first creates a `CommunicationMessage` record in the database with status `queued`, then attempts the dispatch.
- **Inbound Webhooks**: Registered at `apps/admin/app/api/webhooks/resend/route.ts`. 
  - Validates the `svix-signature` to ensure the payload actually came from Resend.
  - Processes `email.delivered`, `email.bounced`, and `email.complained`.
  - Deduplicates events by scanning the JSON `deliveryLog` against the incoming webhook ID.
  - Processes `email.inbound` events to create two-way ticketing/inbox threads via the `In-Reply-To` SMTP header.

## 3. PDF Generation
- **`@react-pdf/renderer`**: Generates structured, vector PDFs purely in Node.js (via Server Actions) without needing Puppeteer or Chromium.
- **Fonts**: Custom bundled `IBM Plex Sans Arabic` handles right-to-left layout constraints ensuring cross-language fidelity.

## 4. Social Analytics Connectors
- Tracks follower counts, engagement, and WhatsApp metrics via the `SocialMetric` database model.
- Polling/Freshness: The dashboard explicitly reports the exact `recordedAt` timestamp and flags `isStale` or `errorStatus` when an API token expires or the platform is unreachable.
