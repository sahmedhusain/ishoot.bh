# Admin UI route audit

The Material 3 implementation was checked against a production build with a disposable test database. The audit visits all 154 dashboard route patterns in both languages, switches 52 local tabs in each language, and measures each state at 390, 768 and 1440 pixels (1,236 viewport measurements).

The measurements found no page-level horizontal overflow, inaccessible off-screen controls outside intentional scroll regions, or visible native selects. Data tables and tab strips may scroll horizontally inside their own region. Temporary draft records cover detail pages; fixtures and optional-module flags are restored after the run.

This is route and layout coverage, not a claim that every data combination, permission state or assistive technology has been tested. Contrast and keyboard suites cover representative pages, menus and dialogs separately. Business workflows retain their existing actions and validation.
